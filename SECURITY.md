# Security Policy

## Supported versions

Only the latest release published on [Firefox Add-ons (AMO)](https://addons.mozilla.org/firefox/addon/tos-summarizer-ai/) receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's private vulnerability reporting:

1. Open the [Security tab](https://github.com/Geralt4/ToS-Summarizer-Extension/security) of the repository.
2. Choose **Report a vulnerability** and describe the issue, the affected version and steps to reproduce.

Please do not open a public issue for security problems. You can expect an initial response within a few days.
